# TrustAge fraud detector

Course project for Corporate Risk Assessment & Digital Transformation (University of Luxembourg, October 2026).

TrustAge is an account-takeover fraud detector for Luxembourg Digital Bank, a fictional bank. Its core idea: a fraudster can steal a password, but not time. Every takeover needs something new on the path to the money (a new device, phone number or payee), so the detector measures how old each link is and, when unsure, buys time before the money leaves.
